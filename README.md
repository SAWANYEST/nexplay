# NEXPLAY 🎮

موقع عربي لألعاب PlayStation وXbox، يشمل كتالوج ألعاب قابل للبحث، صفحات تفاصيل وفيديوهات، حسابات المستخدمين، المفضلة، ولوحة إدارة للتحكم بالألعاب ومحتواها.

## الحالة الحالية

- ✅ كود الواجهة والصفحات والفلاتر، وعرض تجريبي بدون قاعدة بيانات.
- ✅ تدفقات تسجيل الدخول والمفضلة ولوحة الإدارة مبرمجة للاتصال بـ Supabase.
- ✅ تصميم قاعدة بيانات SQL وسياسات RLS ورفع أغلفة الألعاب.
- ✅ فحص نحوي لـ 21 ملف TypeScript/TSX وJavaScript المعاينة (لا يعادل Build كاملًا).
- ⏳ **لم يُربط بعد بمشروع Supabase جديد؛ التسجيل والإدارة غير مفعلين في وضع الاستعراض.**
- ⏳ لا يوجد نشر Vercel أو تحقق عبر المتصفح حتى الآن.

## البداية

1. أنشئ مشروع Supabase جديدًا مستقلًا عن أي مشروع سابق، وتحقق من تكلفة إنشائه قبل الموافقة.
2. نفّذ بالترتيب محتويات:
   - `supabase/migrations/0001_nexplay.sql`
   - `supabase/migrations/0002_seed_games.sql`
3. أنشئ ملف `.env.local` بناءً على `.env.example` وضع **رابط المشروع** و **publishable key** فقط. لا تضع `service_role` في متغير عام.
4. ثبّت الحزم وشغّل المشروع:

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

5. أنشئ حساب المستخدم الذي سيكون المدير وسجّل دخولك. من لوحة Supabase، بعد التحقق من هوية الحساب، أعطِ المستخدم صلاحية المدير (يتم ذلك بواسطة مدير قاعدة البيانات فقط):

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'REPLACE_WITH_YOUR_ADMIN_EMAIL'
on conflict (user_id) do nothing;
```

لا تطبّق هذا الأمر إلا بعد التأكد من عنوان البريد الصحيح. حساب المدير له صلاحيات تعديل كامل كتالوج الألعاب.

6. تأكد من إضافة عنوان موقع الإنتاج ورابط callback في إعدادات **Authentication → URL Configuration** لدى Supabase.
7. أضف نفس المتغيرات في **Vercel Project Settings → Environment Variables** لبيئات الإنتاج والمعاينة المناسبة، ثم اربط المستودع وانشر نسخة Preview قبل الإنتاج.

## حماية البيانات

- `public.admins`: قابل لقراءة عضوية المستخدم نفسه فقط؛ لا توجد صلاحية إدارة عضويات من المتصفح.
- `public.games`: تصفح عام للألعاب المنشورة وغير المؤرشفة. إنشاء وتحديث للأعضاء المصرّح لهم بالإدارة فقط.
- `public.favorites`: كل مستخدم يرى ويعدل مفضلته الخاصة فقط.
- `storage.game-media`: عرض عام، ورفع أغلفة فقط للمدير، مع تقييد MIME والحجم إلى 6MB.
- الحذف في اللوحة **أرشفة قابلة للاسترجاع** لحماية البيانات.
- الأسعار تقديرية وغير مرتبطة بصفحات شراء، ولا يتم دفع أي مبالغ داخل NEXPLAY.

## تخطيط الملفات

- `src/app` صفحات Next.js 15 وواجهات الموقع.
- `src/components` الواجهة التفاعلية ومحرر الإدارة.
- `src/lib/supabase` عميل المتصفح والخادم لتجديد الجلسات.
- `src/lib/seed.ts` محتوى وضع الاستعراض.
- `supabase/migrations` هيكل قاعدة البيانات وبيانات الألعاب الأولية.
- `docs/GOVERNANCE.md` الخطة والقرارات والتسليم.

## قبل الإنتاج

يتطلب نشر الإنتاج: تثبيت الحزم وبناء ناجح، تأكيد 10 ألعاب، تجربة التسجيل وتأكيد البريد، اختبار RLS بمستخدم عادي ومدير، اختبار رفع الصور والأرشفة والاستعادة، الفحص على الهاتف والكمبيوتر، ومراجعة حقوق الصور والأسعار والمنصات والفيديوهات قبل فتح الموقع للعامة.
